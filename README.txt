HICHAM SPONSORING — SITE VITRINE

Publication sur GitHub Pages :
1. Décompressez le ZIP.
2. Ouvrez le dossier hicham-sponsoring-site.
3. Importez index.html dans votre dépôt GitHub (à la racine).
4. Sur GitHub : Settings > Pages > Deploy from a branch > main > /(root) > Save.

Le site est autonome : les images sont intégrées dans index.html.
La langue s'adapte automatiquement à la langue du navigateur. Le bouton en haut permet de basculer FR / AR.
